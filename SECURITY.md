# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within ClaimPilot India, please do NOT open a public GitHub issue. Instead, report the security vulnerability via email to security@claimpilot.in.

Please include:
1. Type of issue (e.g. SQL injection, JWT bypass, XSS).
2. Steps to reproduce the issue.
3. Affected endpoints or source files.

We will acknowledge receipt of your report within 48 hours and provide updates on resolution timeline.
