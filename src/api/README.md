# API Layer (`src/api`)

This directory will contain typed API client modules for interacting with the backend server endpoints:

- `auth.ts` — Authentication endpoints (login, logout, token refresh)
- `claims.ts` — Claim CRUD and state transitions
- `documents.ts` — Document upload and OCR triggers
- `dashboard.ts` — Dashboard KPI aggregations
- `insurers.ts` — Insurer configuration endpoints
